# PACU Medication Mission — 37項藥物外觀辨識遊戲

靜態 HTML5 遊戲，可直接部署至 GitHub Pages。

## 部署
1. 將此資料夾全部檔案上傳到 GitHub repository 根目錄。
2. GitHub → Settings → Pages。
3. Source 選 Deploy from a branch，Branch 選 main / root。
4. 儲存後等待 Pages 網址產生。

## 遊戲內容
- 第1關：6種藥物翻卡配對
- 第2關：12種藥物翻卡配對
- 第3關：18種藥物翻卡配對
- 第4關：37項藥物外觀四選一
- 37項藥物圖鑑
- 錯題複習與 localStorage 紀錄

題庫文字與圖片均取自使用者提供的 Word 文件，未以網路圖片替換。
